═══════════════════════════════════════════════════════════════════════════════
  🚀 UPLOAD PARA HOSTINGER (30 MIN)
═══════════════════════════════════════════════════════════════════════════════

1. Fazer login na Hostinger
   https://hpanel.hostinger.com

2. Ir para "File Manager" (Gerenciador de Arquivos)

3. Navegar para "public_html"

4. Fazer upload dos arquivos:
   • index.html
   • support.js
   • image-slot.js
   • .imageslots.state.json
   • Pasta "assets/" completa

5. Configurar SSL (HTTPS):
   • cPanel → SSL/TLS
   • Auto-Configure com Let's Encrypt
   • Ativar redirect HTTP → HTTPS

6. Ativar Compressão:
   • cPanel → Gzip Compression
   • Marcar .js, .css, .html, .svg

7. Testar:
   • https://seu-dominio.com
   • Verificar se carrega corretamente
